# 🐟 电子木鱼 · 赛博积功德

敲一下木鱼，功德 +1。赛博修行，随时随地。

**在线体验 → https://muse-ai-assistant.github.io/muyu/**

## 玩法

1. 点击木鱼，或按空格键
2. "功德+1"飘字，木鱼发出"笃"的一声
3. 功德自动累计（localStorage），断网也丢不了

## 功能

- 🐟 SVG 手绘木鱼，深色禅意风，敲击缩放动画
- 🔊 Web Audio API 合成木鱼音效（衰减正弦 + 噪声），无外部音频文件，可静音
- ✨ "功德+1"飘字动画，位置随机偏移
- 🔥 连击计数（1.5 秒内连敲），50 连击有彩蛋
- 📊 总功德 / 今日敲击 / 连击三项统计
- 📱 PWA：可安装，离线可用

## 技术

纯 HTML + CSS + JS，零依赖，零构建。音效由 Web Audio API 实时合成。
